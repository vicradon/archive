# Emotion Detection

A pipeline for training an object detection for human emotion detection. It uses the YOLO architecture (YOLOv8) with an augmented dataset of 3300 images.

## Class distribution

The detection is spread across 7 classes:

1. angry	
2. happy	
3. relax	
4. rock	
5. romantic	
6. sad	
7. surprise
