3How K-Nearest Neighbors Works

K-NN is beautifully simple: "Show me who your neighbors are, and I'll tell you who you are!"

1
Calculate distances from test point to all training points
2
Find the k nearest neighbors (closest points)
3
Average their prices to make the final prediction
🔍 Why do we need to scale/standardize features before calculating distances?
To make the algorithm run faster
So features with different units/scales don't dominate the distance
It's not actually necessary for K-NN
⚖️ Scaling Example: Without scaling, a 1mm difference in rainfall might seem tiny compared to a 1°C temperature difference, even though both could be equally important for wine quality!

Here's how to implement K-NN in Python using scikit-learn:

KNeighborsRegressor(n_neighbors=5) ) # Fit the model on training data pipeline.fit(X_train, y_train) # Make predictions on new data predictions = pipeline.predict(X_test) # The pipeline automatically scales X_test using the # same scaling parameters learned from X_train
💻 What does the Pipeline do in this code?
Makes the code run significantly faster
Chains preprocessing and modeling steps together automatically
Improves the prediction accuracy
⚠️ Critical Detail: The pipeline ensures test data gets scaled using the same parameters (mean, std) that were calculated from training data. This prevents data leakage!

6Key Takeaways & Next Steps

🎯 Simple but Powerful

K-NN makes intuitive sense: similar inputs should produce similar outputs. No complex math required!

🔧 No Training Phase

K-NN is "lazy learning" - it doesn't build a model during training, just stores all the data points.

📏 Distance is Key

Always scale features so no single feature dominates distance calculations due to different units.

⚖️ Choosing k Wisely

Small k (1-3) = sensitive to noise
Large k (10+) = smoother, more stable predictions

🏆 Final Challenge: For a dataset with 1000 training points, what's a reasonable starting value for k?
k = 1 (most responsive to local patterns)
k = 5-10 (good balance of local sensitivity and stability)
k = 100 (very smooth but may miss local patterns)
